## 📌 **Descripción**

**IPTracker** es una herramienta profesional de geolocalización de IPs que utiliza la API de [IPinfo](https://ipinfo.io/) para obtener información detallada sobre direcciones IP. Diseñado para ser robusto, eficiente y fácil de integrar en proyectos más grandes.

✅ **Características clave:**
- Consulta de IPs propias o externas (pasando como argumento).
- Manejo avanzado de errores y timeouts.
- Salida formateada y legible en terminal.
- Integración con variables de entorno para tokens sensibles.
- Arquitectura orientada a objetos para mayor reutilización.

---

## 🚀 **Instalación**

### 1️⃣ **Requisitos previos**
- Python 3.8+
- `pip` (gestor de paquetes de Python)

### 2️⃣ **Clonar el repositorio**
```bash
git clone https://github.com/tu-usuario/IPTracker.git
cd IPTracker
```

### 3️⃣ **Instalar dependencias**
```bash
pip install -r requirements.txt
```

> **Nota:** El archivo `requirements.txt` incluye:
> ```
> ipinfo>=4.0.0
> requests>=2.25.0
> colorama>=0.4.4
> python-dotenv>=0.19.0
> ```

---

## ⚙️ **Configuración**

### 1️⃣ **Obtener tu token de IPinfo**
1. Regístrate en [IPinfo](https://ipinfo.io/) y obtén tu token gratuito (o de pago).
2. Guarda el token en un archivo `.env` en la raíz del proyecto:
   ```env
   IPINFO_TOKEN=tu_token_aqui
   ```
   > **⚠️ Importante:** Nunca expongas tu token en el código. Usa variables de entorno o archivos `.env`.

---

## 💻 **Uso**

### 1️⃣ **Ejecutar el script**
```bash
python ip_tracker.py [IP_OPCIONAL]
```
- **Sin argumentos:** Obtiene la IP pública de tu conexión actual.
- **Con argumento:** Ejemplo: `python ip_tracker.py 8.8.8.8` (consulta Google DNS).

### 2️⃣ **Ejemplo de salida**
